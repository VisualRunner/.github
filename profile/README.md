## ✨ What VisualRunner does

VisualRunner combines **visual regression testing**, **localization QA** and **production monitoring** in one workflow.

Use it to:

- 🌍 Capture the same page across multiple languages
- 📱 Test multiple desktop and mobile viewport sizes
- 👀 Detect visual regressions between runs
- 🖥️ Monitor production websites automatically
- 🔍 Compare captures side by side
- 🧩 Highlight visual changes with diff overlays
- 🗣️ Catch localization and layout issues
- 🔗 Configure language variants with URL prefixes, query parameters or cookies
- 📸 Capture complete full-page screenshots
- ⏱️ Run scheduled checks daily, weekly or monthly
- 🌐 Run quick local captures directly from Chrome

---

## 🌍 Built for multilingual websites

Visual problems do not always appear in every language.

A page may look perfect in English while another locale introduces:

- overflowing or clipped text
- missing translations
- broken layouts
- unexpected line wrapping
- different assets
- hidden or displaced elements
- country-specific content differences
- viewport-specific issues

VisualRunner makes these variations part of the QA workflow instead of relying on repetitive manual checks.

---

## 🖥️ Website Monitoring

Create monitors for production pages and let VisualRunner check them automatically over time.

Monitor:

- multiple pages
- multiple languages
- multiple viewports
- different page variants
- scheduled production changes

When something changes, review the current and previous capture side by side and quickly understand what happened.

---

## 🔍 Visual Comparisons

VisualRunner helps you review changes without manually opening and comparing screenshots one by one.

Use:

- side-by-side comparisons
- visual diff overlays
- configurable comparison sensitivity
- previous and current captures
- capture history

This makes it easier to separate expected updates from regressions that need attention.

---

## 🧩 Chrome Extension

The VisualRunner Chrome extension is designed for fast, on-demand visual QA.

Capture the same page across multiple languages and viewport sizes directly from your browser.

Use the extension for quick local checks, while the VisualRunner platform handles recurring monitoring, historical captures and comparisons over time.
