# VisualRunner

Visual QA and website monitoring for multilingual websites.

**Catch localization bugs, visual regressions and production issues before your customers do.**

## What VisualRunner does

VisualRunner helps developers, QA teams and localization teams:

- Capture pages across multiple languages
- Test multiple viewport sizes
- Detect visual regressions
- Monitor production websites automatically
- Compare captures side by side
- Highlight visual changes with diff overlays
- Catch localization and layout issues
- Run quick captures with the Chrome extension

## VisualRunner Platform

Monitor production pages on a schedule and review changes between runs.

VisualRunner supports language and page variations using methods such as URL prefixes, query parameters and cookies.

## Chrome Extension

Capture the same page across multiple languages and viewports directly from Chrome.

The extension is useful for quick local visual QA, while the VisualRunner platform handles recurring monitoring and historical comparisons.
